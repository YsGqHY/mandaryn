## 简体中文

## 新功能

- 应用级音频捕获：只抓指定进程树的输出混音（KOOK / OOPZ / QQ / 微信等正在出声的应用），可枚举应用源并标注默认设备；系统不支持进程级捕获时如实提示并给出设备回环兜底（会包含所有应用声音），不静默降级。
- 录制与转写彻底解耦：录制只采集与落盘，不抢算力；录完存成「录音实例」，之后手动触发或等电脑空闲时自动转写。转写状态与录制主状态是两条独立的轴，转写失败不改写音频与其元数据。
- 可选「边录边转」（默认关）：开启后句末自动定稿并实时出字；推理样本队列满时丢弃推理、绝不阻塞落盘。
- 歌词式回放：文字随进度高亮居中滚动，点击任意片段跳转；拖拽进度只预览、不触发解码；手动滚动即停自动居中，并浮出「回到当前句」。
- 说话人分离与角色命名：会话内声纹自动聚类，角色改名全局同步到历史会话，可手动合并 / 拆分说话人；声纹向量加密落库，不进日志。
- 本地 / 在线双引擎：设置里可切换来源，会话中禁止切换、下一会话生效；在线故障自动回退本地并标记 `degraded`，本地故障不自动回退在线（隐私默认）。
- 离线模型管理：分片下载 + 断点续传 + sha256 校验 + 清单多源回退，支持 zip / tar.gz 离线导入；模型目录可迁移，任一步失败旧目录逐文件不变。
- 整机性能预算：以整机份额为口径，其他应用变忙时自动降档、必要时暂停推理；任何降档都不停止录制与落盘，界面说明降档原因。
- 隐私边界与调试模式：本地模式零出站、无遥测，出站请求全部留痕；在线来源需显式确认风险才能保存；日志只写元数据，调试日志单独落盘并脱敏。
- 快捷键与精简 UX：全局 + 应用内两档快捷键，18 个内置动作，冲突实时校验，可录制 / 恢复默认 / 单动作禁用。
- 三平台分发：Windows 提供 NSIS 安装程序、MSI 与便携 zip（均含 3 个 CGO 运行时 DLL 与第三方许可声明），macOS 提供 universal dmg，Linux 提供 AppImage / deb / rpm；设置页「关于与更新」可检查更新（只提示并打开 Release 页，不做静默自更新）。

## 改进

- 全局 HTTP 代理：`MANDARYN_HTTP_PROXY` / `MANDARYN_HTTP_NO_PROXY` 一处配置同时作用于模型下载与清单获取，支持 `http` / `https` / `socks5` 与凭据加密；配置非法时报错而不是静默直连。
- 设置页新增「网络代理」子页：可保存 / 测试连通性 / 清空，测试结果按 auth、rate-limit、tls、timeout、network 分类给出可操作建议；环境变量接管时显著提示本页配置不生效。
- 能力探测不再把瞬时失败当永久结论：音频服务尚未就绪时描述为「稍后自动重试」，并按 10s 节流自愈，不再长期挂着「本机不支持」的提示。
- 超大通话分页回放：首屏只取 200 条、滚动与播放位置驱动增量补齐、列表窗口化只渲染可视区；1500 句以内的会话行为与分页前完全一致。
- Linux 产物按架构重命名（`mandaryn-<version>-linux-<arch>.*`），消除 deb / rpm 在两个架构下的同名覆盖。
- 发布链路加固：打包阶段不再重建 exe（否则会覆盖签名机取回的已签名产物），发布前补验签闸门，签名失败不再静默发布未签名产物。

## 修复

- 回放高亮与播放时钟完全不跟随播放：监听在 `<audio>` 元素尚未挂载时就早退，且此后不再重绑，导致「歌词式同步」在真实播放路径上失效。改为回调 ref 后元素出现即重绑，并补了走真实播放按钮的回归用例。
- 崩溃恢复从未在生产路径接线：`RecoverUnfinished` / `RepairWAV` 早已实现且有单测，但装配层没有任何调用点，未正常结束的会话不会被修复。现已接入，未正常结束的会话按实际长度补头并标记 `interrupted`，稍后可转写。
- 安装器：覆盖安装前检测运行中的实例，改用映像名匹配（不依赖窗口标题）；静默模式下同样以退出码 2 失败，不再出现「装完了但程序不在」的空目录。
- 卸载页「连数据一起删」勾选框与提示文案早已写好却从未被引用，功能一直是空的；现已真正接上，且默认不勾、静默卸载不删数据。
- 诊断包缺少日志目录接线，导致诊断包实际不含日志；日志滚动时当前文件曾会被清空。两处均已修正。

## English

## New Features

- Application-level audio capture: record only the output mix of a chosen process tree (KOOK, OOPZ, QQ, WeChat and others currently playing audio), with enumerable sources and a default-device badge. Where the OS lacks process-loopback support the app says so honestly and falls back to device loopback (which includes every application); it never downgrades silently.
- Recording and transcription are fully decoupled: recording only captures and writes to disk and never competes for compute. A finished take becomes a recording instance that you transcribe later, manually or automatically while the machine is idle. Transcription status is an independent axis from the recording state machine, and a failed transcription never rewrites audio or its metadata.
- Optional live transcription (off by default): sentences finalize at their end and text appears while recording; when the inference queue is full the samples are dropped rather than blocking disk writes.
- Lyrics-style playback: text highlights and scrolls to center with progress, and clicking any segment seeks to it. Dragging the progress bar only previews and never triggers decoding; scrolling manually stops auto-centering and surfaces a "back to current line" affordance.
- Speaker diarization and role naming: voiceprints are clustered within a session, role renames propagate globally to past sessions, and speakers can be merged or split manually. Voiceprint vectors are stored encrypted and never logged.
- Local and online engines: the source can be switched in settings, forbidden mid-session and applied from the next session. An online failure falls back to local and marks the state `degraded`; a local failure never falls back online, since privacy comes first.
- Offline model management: chunked downloads with resume, sha256 verification and multi-source catalog fallback, plus zip / tar.gz offline import. The model directory can be migrated, and a failed or cancelled migration leaves the old directory byte-identical.
- Whole-machine performance budget: measured as a share of the machine, so the app throttles and, if needed, pauses inference when other applications get busy. No throttling ever stops recording or disk writes, and the UI explains why.
- Privacy boundary and debug mode: local mode is zero-outbound with no telemetry and an audit log for every outbound request; online sources require explicit risk acknowledgement. Logs carry metadata only, and debug logs go to a separate sanitized file.
- Shortcuts and lean UX: global and in-app shortcut scopes, 18 built-in actions, live conflict validation, and per-action record / restore-default / disable.
- Three-platform distribution: Windows ships an NSIS installer, an MSI and a portable zip (all bundling the three CGO runtime DLLs and third-party notices), macOS ships a universal dmg, and Linux ships AppImage / deb / rpm. Settings → About & Updates can check for updates; it only points at the release page and never self-updates silently.

## Improvements

- Global HTTP proxy: `MANDARYN_HTTP_PROXY` / `MANDARYN_HTTP_NO_PROXY` configure model downloads and catalog fetching at once, with `http` / `https` / `socks5` and encrypted credentials. Invalid configuration fails loudly instead of silently going direct.
- A new Network Proxy settings page can save, test connectivity and clear the proxy. Test results are classified (auth, rate-limit, tls, timeout, network) with actionable advice, and the page warns prominently when an environment variable overrides it.
- Capability probing no longer treats a transient failure as permanent: an audio service that is not yet running is reported as "retrying shortly" and recovers on a 10-second retry cadence, instead of pinning an "unsupported on this machine" notice for the whole process lifetime.
- Paged playback for very long recordings: the first page holds 200 segments, scrolling and playback position pull in more, and the list is windowed to the visible range. Sessions of 1500 segments or fewer behave exactly as before.
- Linux artifacts are renamed per architecture (`mandaryn-<version>-linux-<arch>.*`), removing the same-name collision between the amd64 and arm64 deb / rpm packages.
- Release pipeline hardening: packaging no longer rebuilds the executable (which used to overwrite the signed binary fetched back from the signing host), a pre-publish signature verification gate was added, and a failed signature no longer publishes unsigned artifacts silently.

## Fixes

- Playback highlighting and the position clock did not follow playback at all: the media-event listeners bound before the `<audio>` element mounted, returned early, and never rebound, so lyrics sync was dead on the real playback path. A callback ref now rebinds as soon as the element appears, with a regression test that drives the real play button.
- Crash recovery was never wired into the production path: `RecoverUnfinished` / `RepairWAV` existed and were unit-tested, but nothing in the assembly layer called them, so an abruptly ended session was never repaired. It is now wired in — unfinished sessions get their header patched to the real length and are marked `interrupted`, ready to transcribe later.
- Installer: a running instance is now detected before an overwrite upgrade using the image name rather than a window title, and silent mode fails with exit code 2 instead of leaving an empty install directory that looks successful.
- The uninstall page's "delete my data too" checkbox and its warning string had existed unused for a long time, so the feature was simply absent. It is now wired up, unchecked by default, and silent uninstalls keep the data.
- The diagnostics bundle never had its log directory wired, so it shipped without logs, and log rotation could truncate the current file. Both are fixed.

## Upgrade Notes

- This is the first public build; there is no earlier installable version and therefore no upgrade path. The database and tables are created on first launch.
- The three Windows artifacts are **not code-signed** (no certificate in this release). SmartScreen blocks the first run: click "More info" → "Run anyway". Installing to `%ProgramFiles%\Oberon\Mandaryn` needs elevation; use the portable zip to try it without a UAC prompt.
- The macOS artifact is ad-hoc signed and not notarized, so Gatekeeper blocks the first launch. To allow it: Control-click the app in Finder → Open → Open again; or open System Settings → Privacy & Security and click "Open Anyway"; or run `xattr -dr com.apple.quarantine /Applications/Mandaryn.app`.
- The Linux deb / rpm packages require GTK4 and WebKitGTK 6.0, so a recent distribution such as Ubuntu 24.04+, Debian 13+ or Fedora is needed. For the AppImage, `chmod +x` and run.
- The first launch asks for microphone and system-audio permission, used for capture and transcription. Audio, transcripts and voiceprints stay on your machine.
