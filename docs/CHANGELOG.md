# 变更记录（Changelog）

> **用途**：记录 Mandaryn 的产品与工程变更，作为项目唯一的变更历史来源。
> `CLAUDE.md`、`frontend/CLAUDE.md`、`build/CLAUDE.md` 等模块文档只描述**当前约定**，不再各自维护变更历史。
>
> **读者**：全体开发 / 产品 / 测试。排查「某个约定何时引入、为什么这么定」时查这里。

---

## 写作约定

| 项 | 约定 |
|----|------|
| 位置 | 本文件（`docs/CHANGELOG.md`）。项目级变更一律追加到这里，不写回模块 `CLAUDE.md` |
| 顺序 | **按时间升序**追加到末尾，新增条目永远在最后 |
| 格式 | `- YYYY-MM-DD（**主题**）：变更内容`；同日多条可并列，主题用粗体概括 |
| 内容 | 说明**为什么改**与**影响面**；涉及需求编号（`FR-xx-y` / `NFR-xx`）、文档章节（如 `ARCHITECTURE §6.4`）、表（`TBL-xx`）、接口（`API-x.y` / `EV-xx`）时点明 |
| 不写 | 逐行罗列 diff、临时调试过程、与产品行为无关的 Git 操作 |
| 与文档版本的关系 | 单份文档的版本号与简短变更行仍记在各自文末「变更记录」小节；本文件记录**跨文档 / 产品级**的变更脉络 |
